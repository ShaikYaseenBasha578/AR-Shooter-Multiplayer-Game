# AR Shooter Multiplayer Game

A real-time augmented reality multiplayer shooter built in Unity using Niantic's Lightship ARDK. Players engage in AR combat battles across Android and iOS devices in a shared real-world environment.

---

## Features

- **Real-Time Multiplayer:** Engage in live AR battles with other players via Lightship
- **Cross-Platform:** Supports both Android and iOS
- **Augmented Reality Combat:** Fight in AR overlaid on the real world using Niantic's ARDK

---

## Tech Stack

- **Engine:** Unity
- **AR & Multiplayer:** Lightship ARDK (Niantic)
- **Language:** C#
- **Platforms:** Android, iOS

---

## Getting Started

### Prerequisites

- Unity (with Lightship ARDK package installed)
- Niantic Lightship account and API key
- Android or iOS device with AR support

### Installation

1. Clone the repository
```
git clone https://github.com/ShaikYaseenBasha578/AR-Shooter-Multiplayer-Game
```
2. Open the project in Unity
3. Install the Lightship ARDK package via the Package Manager
4. Add your Lightship API key in the project settings
5. Build and run on your Android or iOS device
